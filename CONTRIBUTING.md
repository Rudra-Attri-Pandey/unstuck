# Contributing to Unstuck

Thanks for building with us. Unstuck is for builders, by builders.

## Good first issues

- Add an example of your agent getting unstuck
- Improve the summary line in `src/memory.py`
- Add a new test in `tests/`

## Rules

1. No keys in code. Only `.env.example`.
2. Stdlib first. New deps need a reason.
3. Every fix needs a test.
4. Keep it simple — if a beginner can't read it, simplify it.

## How to run

```bash
python examples/quickstart.py
python -m pytest tests/ -v
```
